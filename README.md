# quiz-game

A p5.js quiz game where the player answers questions. Contains a Contestant class, Question class, and Quiz class managing the game flow. Built with p5.play for sprite interactions.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
